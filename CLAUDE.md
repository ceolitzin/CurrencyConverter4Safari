# CLAUDE.md

Safari web extension (Manifest V3, macOS) that converts a selected price into the user's currency. Plain JavaScript, no dependencies and no build step for the extension itself. The Xcode project in `xcode/` only wraps `extension/` into a macOS app, because that's how Safari ships extensions.

## Commands

```bash
npm test                          # parser tests, Node's built-in runner (make test does the same)
make build TEAM=<team id>         # Release build into build/ (always cleans first)
make install TEAM=<team id>       # build, copy to /Applications, open the app once
make clean
```

Without `TEAM` the app is ad-hoc signed and Safari only loads it with Develop → Allow Unsigned Extensions. The team ID is the `OU=` field of `security find-certificate -c "Apple Development" -p | openssl x509 -noout -subject`.

Nothing in Safari itself can be automated here: after `make install` the user enables the extension in Safari → Settings → Extensions and tests it by hand. To check the UI without Safari, serve a page that loads `parser.js` and `content.js` with a stubbed `chrome.runtime.sendMessage` and `chrome.i18n.getMessage`.

## Layout

- `extension/parser.js`: finds `{ amount, from }` in selected text. Pure, no browser APIs. Exports with `module.exports` under Node and `globalThis.CurrencyParser` in the page, so the same file is the content script and the test subject.
- `extension/content.js`: selection events and the bubble (closed Shadow DOM, `position: fixed`). Talks to the background only through `runtime.sendMessage`.
- `extension/background.js`: service worker. Fetches rates (open.er-api.com, Frankfurter as fallback), caches them 6 h in `storage.local`, does the conversion. Message types: `convert`, `getState`, `saveSettings`.
- `extension/popup.*`: settings (target currency, what a bare `$` means).
- `extension/_locales/{en,es}`: every user-facing string.
- `tests/parser.test.js`: table-driven cases for `parseNumber` and `parseSelection`.

## Conventions

- Use `const api = globalThis.browser ?? globalThis.chrome;` for extension APIs.
- Every user-facing string goes in both `_locales/en/messages.json` and `_locales/es/messages.json`. Don't put `$` in a message (the i18n APIs treat it as a placeholder marker); use `%s` and replace it in JS, as `dollarMeans` does.
- Any parser change gets a test case, positive or negative. Real-world selections that failed are the best cases.
- Parser rules that are easy to break:
  - When the selection has several numbers, convert the one next to a currency marker; fall back to a marker anywhere only if there's a single number.
  - ISO codes count only in uppercase, because ordinary words like "all", "top" and "cup" are also currency codes. The `LOWERCASE_OK` set is the exception, and only right next to the amount.
  - `$` stays `"$"` and is resolved by the `dollarDefault` setting in the background; currency names like "dólares" map to a fixed code.
- Keep the extension dependency-free and avoid features newer than Safari 16.

## Xcode project

Generated by `xcrun safari-web-extension-converter`, then fixed by hand. If it's ever regenerated, reapply:

- App bundle ID `com.ceolitzin.CurrencyConverter` (the converter writes `Currency-Converter`, which breaks the build because the extension is `com.ceolitzin.CurrencyConverter.Extension`).
- `MACOSX_DEPLOYMENT_TARGET = 12.0` at project level too (it defaults to the current SDK).
- Project at `xcode/Currency Converter.xcodeproj`, with extension file paths `../../extension/...`.
- No `DEVELOPMENT_TEAM` committed; it's passed on the command line.

The project lists `extension/` files individually (only `icons` and `_locales` are folder references). **A new file in `extension/` must also be added to the extension target's resources in the Xcode project**, or it won't be in the app.

Xcode registers every app it builds with LaunchServices, so a copy left in `build/` makes Safari list the extension twice. `make install` and `make clean` unregister it; if it happens anyway, `pluginkit -mDAvvv -i com.ceolitzin.CurrencyConverter.Extension` shows which copies are registered.
